# 量化选股分析平台

> **当前版本：[v2.1.0] - 2026-06-04

基于 Flask + ECharts 的 A 股量化分析工具，支持多策略回测、技术指标可视化、ATR 风控和参数优化。

## 更新日志

## [v2.1.0] - 2026-06-04

### 🆕 新增功能

#### 回测与风险管理增强
- **交易成本模型**: 支持设置手续费、滑点等交易成本参数，精确计算实际收益
- **Walk-Forward分析**: 动态参数窗口优化，实现真实的样本外(OOS)检验
- **OOS验证机制**: 将历史数据分为样本内(IS)和样本外(OOS)区间，防止过度拟合
- **批量回测扫描**: 支持一次性对多只股票、多个参数组合进行系统性回测

### 🔧 改进与优化

#### 回测框架
- 集成Walk-Forward引擎，支持自定义IS/OOS分割比例
- 优化批量扫描性能，支持并发回测任务
## [v2.0.0] - 2026-05-28

### 🆕 新增功能

#### 5个新高胜率选股策略
- **多因子共振 (multi_factor_resonance)**: 结合趋势（MA5>MA20>MA60）+ 金叉 + 放量 + 动量，适用于趋势追踪场景
- **MACD+RSI+成交量 (macd_rsi_volume)**: MACD金叉 + RSI超卖 + 成交量放大，捕捉超卖后反弹机会
- **布林带RSI均值回归 (boll_rsi_mean_reversion)**: 跌破下轨+RSI超卖买入，触及上轨或RSI超买卖出，适合震荡行情
- **海龟交易法则 (turtle_trading)**: 经典趋势跟踪策略，突破20日高点买入，跌破10日低点卖出
- **RSI反转+成交量 (rsi_reversal_volume)**: RSI超卖反转+成交量暴增确认，捕捉超跌反弹机会

#### 前端优化
- 策略选择器改为动态加载，从 `/api/strategies` 接口获取最新策略列表
- 新增 `loadStrategies()` 函数自动填充所有可用策略

### 🎯 四维评分系统说明

评分维度（满分100分）:
- **趋势评分** (30分): 均线排列 + MACD状态 + 趋势一致性
- **超买超卖** (25分): KDJ指标 + RSI指标
- **量价分析** (25分): 成交量形态 + OBV资金流向
- **位置运动** (20分): 布林带位置 + 支撑阻力位

评分标准:
- ≥75分: 强买入信号
- 60-74分: 弱买入信号
- 40-59分: 观望
- 25-39分: 弱卖出信号
- <25分: 强卖出信号

## 📖 小白操作指南（3步选股）

### 第1步：打开页面
浏览器访问部署地址，你会看到一个深色背景的股票分析页面。

### 第2步：搜索股票
在顶部搜索框输入**股票代码或名称**（例如 `600519` 或 `茅台`），按回车或点「分析」按钮。

### 第3步：看评分决定买卖

#### 🎯 综合评分（最重要）

| 总分 | 信号 | 操作 |
|------|------|------|
| **≥ 75** | 强买入 🔥 | **优先关注，重点考虑** |
| **60 ~ 74** | 弱买入 ✅ | 可以关注 |
| **40 ~ 59** | 观望 ⏸ | 再看看，别急 |
| **< 40** | 卖出 ❌ | 回避 |

#### 📊 四维评分拆解

买入前逐一核对：

| 维度 | 满分 | 买入要求 | 看什么 |
|------|------|---------|-------|
| **趋势分析** | 30分 | **≥ 20分** | 均线多头排列？MACD金叉？ |
| **超买超卖** | 25分 | — | 超跌时是买入机会 |
| **量价分析** | 25分 | **≥ 16分** | 成交量放大？有资金进场？ |
| **运动与位置** | 20分 | — | 在布林带下轨附近？靠近支撑位？ |

#### ✅ 买入标准（同时满足）
1. 综合评分 **≥ 60**
2. 趋势分 **≥ 20**（不上涨通道不买）
3. 量价分 **≥ 16**（没资金不进场的别买）

#### ❌ 以下情况不买
- 评分 < 40
- 趋势分 < 12（下跌趋势）
- K线在布林带下轨下方
- 回测结果显示亏损

### 高级功能

#### 切换技术指标
点击K线图上方的标签按钮切换显示：
- **MA5/MA10/MA20/MA60** — 均线，判断趋势方向
- **布林带** — 股价在上下轨之间波动，突破上轨超买、下轨超卖
- **MACD** — 金叉买入信号，死叉卖出信号
- **RSI/KDJ** — 超买超卖指标（在独立副图显示）

#### 策略回测
1. 选择交易策略（MA金叉 / EMA交叉 / Dual Thrust / Heikin-Ashi / SAR / 流星线）
2. 设置初始资金、回测天数
3. 点「**运行回测**」
4. 查看结果：
   - **总收益率** > 0 ✅
   - **夏普比率** > 1 ✅（风险调整后收益好）
   - **交易次数** > 3次（样本量够）

#### 参数优化
点「**参数优化**」按钮自动搜索最优参数组合，以夏普比率为目标排序。优化后把最优参数手动填入回测表单验证。

## 功能特性

### 📊 实时行情
- 腾讯财经实时数据接口
- 搜索股票代码/名称
- 最新价、涨跌幅、开盘高开低收、成交量

### 📈 K线图表
- ECharts 交互式蜡烛图
- 可切换 6 种技术指标：MA5/10/20/60、布林带、MACD、RSI、KDJ
- 成交量副图
- 数据缩放/平移

### 🧠 四维评分系统
- **趋势分析** — 均线排列 + MACD 状态 + 趋势一致性（满分 30）
- **超买超卖** — KDJ + RSI 判断（满分 25）
- **量价分析** — 成交量形态 + OBV 资金流向（满分 25）
- **运动与位置** — 布林带位置 + 支撑阻力检测（满分 20）
- 综合评分自动产生信号：强买入/弱买入/观望/弱卖出/强卖出

### 🛡️ ATR 风控
- 自动计算 ATR(14) 波动率指标
- 动态止损价（2 倍 ATR）
- 动态止盈价（3 倍 ATR）

### 🔄 多策略回测
支持 4 种交易策略：

| 策略 | 说明 | 方向 |
|------|------|------|
| **MA5/MA20 金叉** | MA5 上穿 MA20 买入，下穿卖出 | 仅做多 |
| **Dual Thrust 通道突破** | 基于前 N 日 HH/LC 范围设定突破通道 | 多空双向 |
| **Heikin-Ashi 均值 K 线** | Heikin-Ashi 蜡烛图形态识别 | 多空双向 |
| **Parabolic SAR 抛物线** | 抛物线指标趋势跟踪，自动反转 | 多空双向 |

- ATR 动态止损止盈
- 多空双向交易支持
- 资金曲线、胜率、夏普比率、最大回撤、盈亏比等指标

### ⚡ 参数优化
- 网格搜索最优参数组合
- 以夏普比率为目标自动排序
- 展示 Top 10 参数排名

### 🔧 技术指标
MA / EMA / MACD / RSI / KDJ / BOLL / ATR / OBV / 支撑阻力

## 快速开始

### 环境要求
- Python 3.10+
- pip

### 安装

```bash
git clone https://github.com/yhwl8888/stock_quant_platform.git
cd stock_quant_platform
pip install -r requirements.txt
```

### 运行

```bash
python app.py
```

访问 `http://localhost:8000`

内网其他设备访问 `http://<本机IP>:8000`

### 使用

1. 在搜索框输入股票代码或名称（如 `600519` 或 `茅台`）
2. 点击「分析」或按回车
3. 查看实时行情、K 线图、综合评分
4. 切换技术指标标签
5. 选择策略并点击「运行回测」
6. 点击「参数优化」自动搜索最优参数

## API 接口

| 端点 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 页面入口 |
| `/api/search?q=关键字` | GET | 搜索股票 |
| `/api/quote/<code>` | GET | 实时行情 |
| `/api/kline/<code>?days=250` | GET | K 线数据 |
| `/api/indicators/<code>` | GET | 技术指标 |
| `/api/analysis/<code>` | GET | 综合评分 |
| `/api/backtest` | POST | 策略回测 |
| `/api/optimize` | POST | 参数优化 |
| `/api/strategies` | GET | 策略列表 |
| `/api/support-resistance/<code>` | GET | 支撑阻力 |
